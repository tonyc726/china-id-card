0 依赖

无任何第三方依赖，minzip 体积不足 2KB，安全可靠，无供应链风险

严格校验

ISO 7064:1983 MOD 11-2 加权校验码 + 省份代码 + 出生日期合法性多重验证

信息解析

一行代码解析省份、出生日期、性别、年龄，支持 15 位升 18 位转换

脱敏处理

内置 mask() 脱敏函数，显示前 3 后 4 位，满足隐私合规展示需求

TypeScript 原生

完整类型定义，strict 模式开发，接口即文档，IDE 智能提示开箱即用

全端兼容

同时输出 ES / CJS / UMD 三种格式，Node.js 与浏览器环境通吃

typescript
import { isValid, parse, mask } from 'china-id-card';

// 快速验证
isValid('622922197808118498'); // → true

// 解析完整信息
const info = parse('622922197808118498');
// → { isValid: true, province: '甘肃省', birthDate: '1978-08-11',
//     gender: 'male', age: 46, ... }

// 脱敏处理
mask('622922197808118498'); // → '622***********8498'
