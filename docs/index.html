China ID Card Validator

基于 GB 11643-1999 标准的中华人民共和国公民身份证号码验证工具库。支持 15 位和 18 位身份证的验证、解析和转换。

isValid(id) — 快速验证

推荐
Live Demo
结果
-
import { isValid } from 'china-id-card';

// 快速验证身份证是否有效
isValid('622922197808118498'); // → true
isValid('123456789012345678'); // → false
